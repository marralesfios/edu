Programming fun facts

  1. In C++, unstoppable_token is a refinement of stoppable_token. That is, all unstoppable tokens are stoppable tokens.
  2. Python used to hash all NaNs to 0, but because NaNs are not equal to each other, you can have multiple NaNs as dictionary keys. This caused guaranteed hash collisions until it was fixed in Python 3.10.
  3. While in C++, ++3 is not valid, you can use ++const_cast<int&>(static_cast<const int&>(static_cast<int&&>(3))) to achieve the effect of creating a temporary int of value 3 and incrementing it. Yes, this is not undefined behavior (though it would be if you remove the innermost cast).
  4. In C++, export is a fully reserved keyword but import is only a contextual keyword (i.e. can be used as an identifier).
  5. APL's scan operator has quadratic runtime because it scans increasingly long prefixes of the array while doing each reduction step right-to-left. (in other words, f\a b c returns a then a f b then a f (b f c), which cannot be optimized when f cannot be proven to be either commutative or associative)
